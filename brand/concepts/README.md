# Drishti Rachana: logo concepts

Copyright (c) 2026 Ashutosh Sinha. Proprietary. All rights reserved.

Palette and weight follow the Drishti family: ink `#14202b` on light, `#e6edf3` on dark, one amber accent `#e8a33a`. Marks use `currentColor` plus a single amber shape, so dropping the amber (one-colour use) still reads. No gradients, no embedded fonts; the wordmark is live text in a system font stack (Inter, Segoe UI, Helvetica Neue, Arial). Convert the text to outlines before print or production use.

Files per concept X: `X-logo.svg` (for dark backgrounds), `X-logo-light.svg` (for light backgrounds), `X-mark.svg` (square, 64 x 64). Overview: `concepts.png`.

## A. Composition grid
The Drishti lens (the same eye silhouette as Elements) with a three-panel screen snapped inside: one tall panel, two stacked ones, the lower in amber. Meaning: Rachana is what Drishti sees, composed as a screen. Closest to the family, but at 16 px it is the most eye-like and the panels become a smudge.

## B. Sutra thread
One continuous round-capped line draws an R (stem, bowl, leg) and ends in an amber point, the needle end of the thread. Meaning: sutra is thread; one declaration yields one composed layout. Simplest, scales best, strongest at 16 px; the least "dashboard" of the three and the most generic letterform.

## C. Block R
An R assembled from layout blocks with gaps, as a grid layout would place them; the amber block is the one being placed. Matches the pixel-built Elements wordmark. Reads as a layout rather than a letter, so the R is the weakest here.

## Recommendation
B for clarity and small-size strength; pair it with the Elements lens in docs to keep the family tie. If the family look matters most, choose A.
